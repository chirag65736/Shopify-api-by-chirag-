# Shopify Checker API

## Deploy on Railway

1. Push this repo to GitHub.
2. Go to https://railway.app → New Project → Deploy from GitHub.
3. Select your repo.
4. Railway auto-detects Python and uses `requirements.txt` + `Procfile`.
5. Add environment variable if needed (none required for basic use).
6. Get your public URL from Settings → Networking → Generate Domain.
